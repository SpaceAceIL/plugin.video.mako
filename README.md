# Mako Live - Kodi Addon

Made by **SpaceAce** <space@anan.media>

Play the Mako / Channel 12 live stream directly inside Kodi.

## Install

1. Download `plugin.video.mako.zip` from Releases.
2. Kodi -> Settings -> Add-ons -> Install from zip file.
3. Install InputStream Adaptive:
   Settings -> Add-ons -> Install from repository ->
   Kodi Add-on Repository -> VideoPlayer InputStream -> InputStream Adaptive.
4. Restart Kodi. Add-ons -> Video add-ons -> Mako Live.

## Requires

- Kodi 19+
- inputstream.adaptive
- pycryptodome (bundled with most Kodi builds)
- Israeli IP
